# Postmortems

One file per accident: `yyyy-mm-dd-topic.md`.

```markdown
# YYYY-MM-DD — <short title>

## Summary

## Impact

## Cause

## Fix

## Follow-up
```

Follow-up may open a `LESSONS.md` draft or an Agent Note. This file is not a lesson draft.

A defect found in self-test or testing goes in [LESSONS.md](../../LESSONS.md). An on-the-spot correction goes in [.agents/prefs/](../../.agents/prefs/README.md).
